This is a guide for modding OG version, inspired by the Midnight Ride guide but this one will support 1.10.163.0 forever

# Requirements

- English version
- All DLCs (don't use the HD Texture Pack)
- Steam/GOG version (Epic Games & Windows Store version are not supported by this guide, and probably can't downgrade to 1.10.163.0, if possible let me know [here](https://github.com/Synaelle/modding-guides/issues))
- Windows 7 x64 or higher (Windows 10 or higher is recommended)
- **Clean installation of the game** (Uninstalling is not enough, you need to remove the installation folder)

# Mod Organizer 2
- This guide uses Mod Organizer 2, you're free to use Vortex but you will be on your own for MO2 specific instructions
[Windows 10/11](https://github.com/ModOrganizer2/modorganizer/releases/download/v2.5.2/Mod.Organizer-2.5.2.exe) - [Windows 7/8.1](https://github.com/ModOrganizer2/modorganizer/releases/download/v2.4.4/Mod.Organizer-2.4.4.exe)

- I **highly recommend** you do not install Mod Organizer inside Program Files, create a folder in the root of your disk drive called Modding or something you will recognize

- When opening Mod Organizer, select **a portable instance**

# Nexus Mods

Almost all mods are on Nexus Mods, you will need an account

# This is an older version

This guide will help you mod an **older** version of the game, called "OG"

If a mod author doesn't support the version, I will note it under the specific mod
